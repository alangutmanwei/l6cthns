# Description
RunTracingAnalysis.m lets the user set the input files and metadata for axon and dendrite tracing in .swc file format, with an additional rightmost column that adds the annotated cortical layer location for each point in the tracing that is generated by VisualizeLayers_funcY (Python). ProcessReconstruction, GenerateGridData, HorizontalSegmentAnalysis, and figQuality provide additional MATLAB functions called during the analysis pipeline.
